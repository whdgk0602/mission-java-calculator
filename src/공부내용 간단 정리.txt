1. MVC 패턴 (Model-View-Controller)
MVC는 소프트웨어 아키텍처 패턴으로, 애플리케이션을 세 가지 주요 구성 요소로 나누어 관리하는 방법
	1) Model:
		o애플리케이션의 데이터와 비즈니스 로직을 담당
		o데이터베이스와의 상호작용, 데이터 처리 및 비즈니스 규칙 등을 포함
		o예: 사용자 정보 처리, 계산 작업 등.
	2) View:
		o사용자 인터페이스(UI)를 담당
		o사용자에게 데이터를 어떻게 보여줄지 결정하는 역할을 하며, 모델 데이터를 바탕으로 화면을 업데이트
		o예: HTML 페이지, 모바일 앱 UI 등.
	3) Controller:
		o사용자의 입력을 처리하고, 그에 따라 모델과 뷰를 업데이트하는 역할
		o모델을 업데이트하거나 뷰를 변경하는 로직을 구현
		o예: 사용자가 버튼을 클릭했을 때, 해당 이벤트를 처리하여 모델을 갱신하고 뷰를 다시 그리는 작업 등.
	
	주요 특징
		o유지보수성: 각각의 구성 요소(Model, View, Controller)가 분리되어 있어, 코드 변경 시 다른 부분에 미치는 영향을 최소화 가능
		o테스트 용이성: 각 구성 요소가 독립적으로 테스트할 수 있어 효율적인 단위 테스트가 가능
		o확장성: 새로운 기능을 추가할 때 기존 구조를 크게 변경하지 않고 확장 가능
	사용되는 곳
		o웹 애플리케이션: Spring MVC, Django, ASP.NET MVC 등.
		o모바일 애플리케이션: iOS의 MVC 패턴, Android의 MVVM(Model-View-ViewModel) 패턴 등.


2. Stream API
Stream API는 Java 8에서 도입된 기능으로, 컬렉션 처리를 선언형 프로그래밍 방식으로 할 수 있도록 도와줌. 반복문 대신 스트림을 이용해 데이터를 처리하는 방식

	1) Stream:
		o데이터의 흐름을 나타내며, 컬렉션, 배열 등의 데이터를 쉽게 처리
		o내부적으로 병렬 처리나 지연 평가를 지원하여 성능 최적화가 가능
	2) 중간 연산 (Intermediate Operations):
		o데이터를 변환하거나 필터링하는 연산입니다. 중간 연산은 지연 평가방식으로, 실제 연산은 최종 연산이 호출될 때까지 수행되지 않음
		o예: filter(), map(), distinct(), sorted(), flatMap() 등.
	3) 최종 연산 (Terminal Operations):
		o스트림을 최종적으로 처리하고 결과를 반환하는 연산입니다. 이 연산이 실행될 때 스트림이 실제로 계산됨
		o예: collect(), forEach(), reduce(), count(), anyMatch() 등.
	주요 특징
		o선언적 프로그래밍: 코드가 간결하고 가독성이 높아짐
		o병렬 처리: .parallelStream()을 사용하여 데이터를 병렬 처리 가능. 이를 통해 멀티코어 시스템에서 성능을 최적화 긴,ㅇ
		o지연 평가: 중간 연산은 실제로 데이터가 필요할 때까지 실행되지 않아 성능을 최적화
Stream API는 주로 사용하면서 공부했음
